# Mini-Weather-Station
A Project I completed in late 2025 to early 2026, where I used an Arduino and build a live weather station that would send data over into a python script which visualised the data into graphs.

Main Components Used: 

- Arduino Uno R3
- DHT11 Temperature and Humidity Sensor
- LCD1602 Module

Arduino programmed using C++ and data logger and graphs programmed using Python
